# 吉林大学本科绩点计算器（JLU GPA Calculator）

> 作者：DailyPotato · 共同作者：Coldymemos
>
> @Coldymemos：PRTS感谢大家的支持，使用过程中有需要优化的问题请及时联系哦。

本项目为面向吉林大学本科生的本地优先绩点核算工具，可计算保研 GPA、加权平均分和算术平均分。

应用部署为 GitHub Pages 静态 PWA。成绩文件只在浏览器中解析，课程和设置保存在当前浏览器的 IndexedDB 中，不上传任何服务器。

> **非官方系统**：本项目不是吉林大学官方系统。请按适用年份、学院和专业文件核对后使用。

## 功能特性

### 成绩导入

- 支持 `.xls`、`.xlsx`、`.csv`，适配吉林大学常见成绩表表头；
- 导入前预览、多工作表选择、逐行问题报告（警告 / 错误），支持部分成功；
- 覆盖或追加两种合并模式；
- 导出带「是否排除」列的适配课程表格，再次导入时自动恢复课程手动排除状态。

### 三项计算

- **保研 GPA**：按分数—绩点映射表计算；
- **加权平均分**：按学分加权；
- **算术平均分**：按课程门数平均；
- 同一课程号只保留最高有效成绩参与计算，同名不同号不合并；
- 成绩支持百分制和五级制，五级制默认折算为 优秀 95、良好 85、中等 75、及格 65、不及格 0；
- 绩点来源可选「优先采用教务导入绩点」或「按分数映射重新计算」。

### 课程管理

- 手动新增、编辑、删除课程，支持课程号、课程名、学年学期、学分、课程类别、课程性质等字段；
- 逐门设置是否参与均分、是否为保研课程（自动 / 纳入 / 排除）、成绩记录是否有效；
- 支持清空课程清单，或在「关于」对话框中一键重置全部数据（课程、排除规则与设置）。

### 排除规则与过滤配置

- 每项结果（保研 GPA / 加权平均分 / 算术平均分）独立配置排除规则：课程类型（必修 / 选修）、关键词、课程编号；
- 结果明细展示实际采用与排除的课程及具体原因；
- 过滤配置可导出为 JSON 文件并随时重新导入。

### 结果导出

- 结果摘要卡片导出为 PNG 或 PDF，包含规则信息、五级制折算表和生成时间；
- 课程明细与适配表格导出为 `.xlsx`。

### 本地优先与离线

- IndexedDB 自动保存课程与设置；
- PWA 支持离线访问；
- 移动端适配：手机端自动切换为汉堡菜单侧边栏与课程卡片列表；
- 成绩数据仅在浏览器本地处理，不经过任何服务器。

## 技术栈

| 类别   | 选型                                                  |
| ------ | ----------------------------------------------------- |
| 框架   | React 19 + TypeScript + Vite 8                        |

## 项目结构

```text
src/
├── domain/           # 领域层：课程模型、计算逻辑、规则集
│   ├── calculation/  #   计算结果、预处理、查重、格式化
│   ├── course/       #   课程 schema / 类型 / 规范化
│   └── rules/        #   绩点映射、保研规则、结果排除规则
├── application/      # 应用层用例：导入课程、合并课程
├── infrastructure/   # 基础设施：导入器、导出器、IndexedDB、过滤配置
└── ui/               # 界面层：React 组件、App 状态
```

## 本地开发

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

常用脚本：

| 命令                            | 说明                                                   |
| ------------------------------- | ------------------------------------------------------ |
| `pnpm dev`                      | 启动开发服务器                                         |
| `pnpm check`                    | 完整校验：lint + 格式检查 + 单元测试 + 类型检查 + 构建 |
| `pnpm test` / `pnpm test:watch` | 单元测试（Vitest）                                     |
| `pnpm test:e2e`                 | 端到端测试（Playwright）                               |
| `pnpm build`                    | 生产构建                                               |
| `pnpm preview`                  | 预览生产构建                                           |

## 部署

生产构建默认使用 GitHub Pages 子路径 `/JLU-GPA-Calculator/`。推送 `main` 分支时，GitHub Actions（`.github/workflows/deploy.yml`）自动执行完整校验并部署到 GitHub Pages；拉取请求会运行校验但不部署。

## 数据与隐私

- 课程与设置仅保存在当前浏览器的 IndexedDB 中；
- 首次使用（本地无任何缓存数据）会自动展示「关于」说明，强调数据均在本地处理与缓存、不会收集信息；
- 可在应用内「关于 → 数据管理」一键清空全部本地数据（课程、排除规则与设置）；
- 清除浏览器站点数据会同时清除本地保存的内容；
- 真实成绩文件、导出结果和本地验收数据禁止提交到仓库。
